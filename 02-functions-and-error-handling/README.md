# Project 2: Robot Data Manager

## Learning Goals
- Combine functions, files, and exception handling
- Build a complete robot data management system
- Practice real-world programming patterns

## Your Project
Create a system that:
- Uses **functions** to organize code
- **Reads/writes** robot data to files (JSON + text report)
- **Handles errors** gracefully (missing file, corrupt JSON, invalid data)

## Success Criteria
**Technical** – all functions work, file operations succeed, exceptions are
handled, the program runs without crashing.

**Understanding** – explain parameters and return values, file modes, and when
to use exception handling.

**Confidence** – write functions from scratch, read/write files, handle errors.

## Run
```bash
cd starter
python robot_data_manager.py
```

- `starter/` – start here; complete the `TODO`s
