# Python for Robotics – Course Projects

Hands-on projects for the **Python for Robotics** course. Each section has a
project with **starter code** (your workspace) and a **reference solution**.

## Projects

| # | Section | Project | Starter | Solution |
|---|---------|---------|---------|----------|
| 01 | Python Fundamentals | Complete Robot Control System | [starter](01-python-fundamentals/starter) | [solution](01-python-fundamentals/solution) |
| 02 | Functions & Error Handling | Robot Data Manager | [starter](02-functions-and-error-handling/starter) | [solution](02-functions-and-error-handling/solution) |
| 03 | Object-Oriented Programming | Robot Management System | [starter](03-object-oriented-programming/starter) | [solution](03-object-oriented-programming/solution) |
| 04 | Advanced Python Concepts | Advanced Robot Software System | [starter](04-advanced-python-concepts/starter) | [solution](04-advanced-python-concepts/solution) |

## Repository Structure

```
python-for-robotics/
├── 01-python-fundamentals/
│   ├── README.md          # project instructions
│   ├── starter/           # your code goes here
│   └── solution/          # reference solution
├── 02-functions-and-error-handling/
├── 03-object-oriented-programming/
└── 04-advanced-python-concepts/
```

## Getting Started

Requires **Python 3.10+**.

```bash
git clone https://github.com/<your-org>/python-for-robotics.git
cd python-for-robotics
```

## Running a Project

```bash
# Project 1
python 01-python-fundamentals/starter/robot_control_system.py

# Project 2
python 02-functions-and-error-handling/starter/robot_data_manager.py

# Project 3  (run from inside the folder)
cd 03-object-oriented-programming/starter && python main.py

# Project 4
cd 04-advanced-python-concepts/starter && python main.py
```

Swap `starter` for `solution` to run the finished version.

## How to Use

1. Read the project `README.md`
2. Complete the `TODO`s in `starter/`
3. Run and test your program
4. Compare with `solution/`
